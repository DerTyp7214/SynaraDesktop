# Synara Desktop

Compose Multiplatform desktop client for the Synara music server.

## Modules

| Module | Purpose |
|---|---|
| `synara` | The app itself (UI, player, RPC layer, local database) |
| `app` | Desktop launcher (`dev.dertyp.synara.MainKt`) |
| `classic` | Alternative "classic" launcher (`dev.dertyp.classic.MainKt`) |
| `tray` | Tray UI module |
| `common-rpc` | Git submodule shared with the server and mobile apps (RPC interfaces and models) |
| `dbus-api`, `dbus-compiler` | D-Bus API definition and code generator (Linux media controls) |
| `icon-processor` | Icon generation for packaging |

## Prerequisites

- A JDK on your `PATH` (`java -version`); the Gradle wrapper downloads everything else.
- The `common-rpc` submodule checked out:

```bash
git submodule update --init --recursive
```

## Start the app

Run the desktop app from source:

```bash
./gradlew :app:run
```

The classic launcher:

```bash
./gradlew :classic:run
```

The first run compiles everything and takes several minutes. Later runs are much faster.

A build started this way is a **debug build**: it keeps its config, cache and data in the git-ignored `dev/` folder of the repository (`dev/config`, `dev/cache`, `dev/data`), so it never touches the state of an installed Synara.

## Compile only

To check that the code compiles without launching a window:

```bash
./gradlew :synara:compileKotlinJvm
```

## Package

Native installers (Deb, Msi, Dmg for the current platform):

```bash
./gradlew :app:packageDistributionForCurrentOS
```

An unpacked distributable image:

```bash
./gradlew :app:createDistributable
```

Packaged builds are release builds and use the regular per-user config directory of the operating system.

## Generated documentation

- [docs/RPC_SERVICES.md](docs/RPC_SERVICES.md) — RPC services and models, generated from `common-rpc`.
- [docs/DBUS_API.md](docs/DBUS_API.md) — D-Bus API, generated from `dbus-api`.

Both are regenerated by the pre-commit hook in `.githooks` when the corresponding sources change. Enable the hooks once with:

```bash
git config core.hooksPath .githooks
```
